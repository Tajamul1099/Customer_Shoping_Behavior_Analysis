# 🛍️ Customer Shopping Behavior Analysis

## 📌 Overview
This project analyzes customer shopping behavior to uncover purchasing patterns, trends, and key business insights. It covers the complete data analytics workflow — from data loading and cleaning to visualization and reporting.

## 📂 Dataset
* Contains customer transaction data including:
  * Customer details
  * Product categories
  * Purchase amounts
  * Ratings and behavior metrics
* Data was preprocessed and cleaned for analysis.

## 🛠️ Tools & Technologies
* **Python** (Pandas, NumPy, Matplotlib, Seaborn) – Data cleaning & EDA
* **SQL (MySQL)** – Data querying and analysis
* **Power BI** – Interactive dashboard creation
* **PowerPoint** – Final presentation

## 🔄 Project Workflow
### 1. Data Loading & Exploration
* Loaded dataset using Python
* Performed initial exploration (shape, data types, missing values)

### 2. Data Cleaning
* Handled missing values
* Removed duplicates
* Standardized data formats

### 3. Exploratory Data Analysis (EDA)
* Analyzed customer purchase patterns
* Identified trends in categories and spending
* Visualized key insights using charts

### 4. SQL Analysis
* Imported cleaned data into MySQL
* Wrote queries to extract business insights:

  * Top-selling categories
  * Customer segmentation
  * Revenue trends

### 5. Dashboard Creation (Power BI)
* Built an interactive dashboard including:
  * KPIs (Total Customers, Average Purchase, Ratings)
  * Sales by category
  * Customer behavior insights

### 6. Reporting & Presentation
* Created a detailed report summarizing findings
* Designed a PowerPoint presentation for stakeholders

## 📊 Dashboard
Key features of the Power BI dashboard:

* Customer distribution by subscription status
* Sales analysis by category
* KPI cards for quick insights
* Clean and interactive visual design

## 📈 Results & Insights
* Identified high-performing product categories
* Analyzed customer spending behavior
* Discovered trends that can improve marketing strategies
* Provided actionable insights for business decision-making

## 📎 Conclusion
This project demonstrates an end-to-end data analytics workflow, combining Python, SQL, and Power BI to generate meaningful business insights from raw data.
